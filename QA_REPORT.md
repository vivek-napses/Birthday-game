# QA Report

## Cycle 1
- **Score:** 6/10
- **Physics:** Jump and gravity logic were correct, but the game had only one fixed jump interaction and no difficulty ramp.
- **Looks:** The scene was clean but too generic, with flat primitive visuals and a goal marker that did not meaningfully sell progress.
- **Gameplay:** Win/lose/restart worked, but progression was flat, some collectibles could be grabbed without jumping, and accessibility feedback needed improvement.
- **What changed for next iteration:** Added a tighter player hitbox, visible progress feedback, mild difficulty scaling, smarter spawn handling, higher collectibles, keyboard/accessibility fixes, and simple player animation.

## Cycle 2
- **Score:** 7/10
- **Physics:** Collision fairness improved and the speed/spawn ramp added better pacing, but the mechanic set was still intentionally simple.
- **Looks:** Progress visuals and animation were better, but the game still needed more obvious birthday-themed set dressing and more visual variety.
- **Gameplay:** The loop became more skill-based and readable, though a small low-collectible band could still be collected while grounded.
- **What changed for next iteration:** Raised collectible heights again and added bunting, balloons, cake/candles at the goal, and a gift-box obstacle variant.

## Cycle 3
- **Score:** 8/10
- **Physics:** The tuned hitbox and difficulty ramp kept the game fair and responsive for a lightweight browser runner.
- **Looks:** Birthday visuals now read clearly through the celebratory goal stage, balloons, bunting, and obstacle variety while staying lightweight.
- **Gameplay:** All collectibles now require a jump, score progression is clear, and the run remains skill-based through to the win state.
- **What changed for next iteration:** No further iteration needed; minimum target score was reached.
